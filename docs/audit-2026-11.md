## Decisions and recommendations

| Decision | Chosen now | Recommendation |
|---|---|---|
| Ads | Opt-in consent, skipped for crawlers/reduced-data/saveData/webdriver | Keep opt-in; do not auto-load AdSense |
| Deprecated `api_key` query parameter | Still accepted, header preferred | Remove after confirming no external clients use it |
| `/php/*` compatibility endpoints | Kept; documented as legacy | Remove after client migration |
| OpenWidget on live site | Not added to repo; flagged as stale/injected | Owner should clean production HTML/server injection |
| SSR/prerender | Design note only | Prerender public static routes; keep `/u/:id` server-rendered |
| Real 404 status | Not possible with current SPA fallback | Revisit after prerendering or server-side routing |
| Lighthouse | Not runnable locally | Add a Chrome-enabled CI job or run manually before release |
| SVG minification / large component splits | Skipped | Do only if subsequent Lighthouse profiling justifies the risk |
| Security headers/CSP | Documented, report-only | Apply via nginx snippet, monitor reports, then tighten CSP |
